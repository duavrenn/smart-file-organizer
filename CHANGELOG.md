# Changelog

All notable changes to this project will be documented in this file.

## [0.1.0] - First public release
- Project scaffold and architecture
- `FileOrganizer` basic coordinator implemented
- `config` loader with validation and environment overrides
- `logger` service (Winston) with structured JSON logs
- `DuplicateDetector` service with SHA-256 hashing
- Unit tests for `FileOrganizer` and `DuplicateDetector` core behaviors
- Basic `README`, `CONTRIBUTING`, license, and .gitignore updates
